# Testes do Citizen Assist Energia

## 1. Objetivo

Registrar os testes funcionais realizados no Citizen Assist Energia, verificando o funcionamento das buscas, cálculos, indicadores, exportação de dados e orientações da base de conhecimento.

## 3. Correções realizadas

Durante os testes, foi identificado um erro na função de atendimento de perguntas, relacionado à indentação e ao controle da variável utilizada para tentar novamente.

A função foi corrigida e testada novamente.

Após a correção, o sistema passou a registrar corretamente as perguntas sem resposta e a permitir novas tentativas.

## 4. Resultado dos testes

Os testes funcionais realizados demonstraram que os principais recursos do sistema estão funcionando, incluindo a busca de orientações, o registro de atendimentos, os indicadores, a exportação dos dados e os cálculos de energia.

Também foram testadas novas orientações sobre consumo consciente e energia solar, com apresentação das respectivas fontes de informação.

## 5. Limitações

Os testes registrados neste documento são testes funcionais realizados durante o desenvolvimento.

A validação com usuários externos deverá ser registrada separadamente, caso ainda não tenha sido realizada. Os resultados de uso real não devem ser considerados comprovados apenas pelos testes internos.

## 6. Considerações finais

Os testes contribuíram para identificar e corrigir problemas durante o desenvolvimento, além de verificar o funcionamento das principais funcionalidades do Citizen Assist Energia.
